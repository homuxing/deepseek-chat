# 对话图片预览

## 显示与交互

- 图片附件在消息中显示缩略图，文档附件继续显示文件卡片；图片与文档混排时使用较小的缩略图。
- 点击缩略图后在当前页面的遮罩中显示完整图片，适应桌面与移动端视口，不打开新窗口。
- 支持关闭按钮、点击空白处与 Esc 关闭；同条消息中的多张图片可通过按钮和左右方向键切换。
- 预览期间限制焦点与背景交互，关闭后恢复焦点；切换会话或消息版本后收起预览。
- 加载中、原件缺失、读取失败和图片损坏分别显示实际状态。

## 原件数据流程

- 发送时将本次选中的原件交给会话附件资源，缩略图立即读取这份原件，与服务端保存进度独立。
- 同一原件的并发读取共用资源；保存失败时保留待保存原件，保存完成后释放多余资源。
- 资源随附件显示与待保存状态管理，切换账号和替换历史时清理，避免旧请求覆盖新状态。

## 验证

验证发送后立即预览、慢速保存、保存失败与恢复、历史图片、混合附件、多图切换、预览关闭、会话与版本切换、移动端、原件缺失、损坏图片和并发读取。
